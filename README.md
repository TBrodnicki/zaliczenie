# ZOO online

Projekt zaliczeniowy przygotowany w ramach przedmiotu **Zarządzanie projektem wdrożeniowym**.

## Opis projektu

ZOO online to prosta strona internetowa prezentująca wybrane zwierzęta. Każdy uczestnik projektu dodaje własną sekcję HTML dotyczącą wybranego zwierzęcia, wraz ze zdjęciem i krótkim opisem.

Projekt pozwala przećwiczyć podstawowe elementy pracy zespołowej w projekcie wdrożeniowym:

- planowanie zadań w Trello,
- pracę z repozytorium Git,
- tworzenie osobnych gałęzi,
- wykonywanie commitów,
- wysyłanie zmian na GitHub,
- tworzenie Pull Requestów.

## Moje zadanie

Moim wybranym zwierzęciem jest **pingwin**.

Zakres wykonanej pracy:

- utworzenie gałęzi `pingwin-tomasz`,
- dodanie zdjęcia pingwina do katalogu `img/`,
- dodanie sekcji HTML opisującej pingwina,
- przygotowanie Pull Requesta do repozytorium prowadzącego.

## Technologie

Projekt wykorzystuje:

- HTML5,
- Git,
- GitHub,
- Trello.
